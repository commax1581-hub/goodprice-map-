# 착한가격 지도

행정안전부 **착한가격업소** 공공데이터 13,000여 곳을 지도에서 찾아보는 웹앱입니다.
개인이 공공데이터로 만든 **비공식** 포트폴리오 프로젝트입니다.

🔗 https://goodprice-map.pages.dev

## 주요 기능
- **지도 + 목록:** 시도·시군구 → 업종 → 가격·영업중·시설 조건 → 검색 순서로 좁혀 보기
- **문장 검색:** "부산 중구 국밥 7천원 이하", "아이랑 갈만한 곳" 같은 문장을 규칙으로 해석하고, 못 읽으면 AI(Gemini)가 해석
- **길찾기·후기·현장 확인:** 카카오·네이버·구글·티맵으로 바로 연결 (평점은 저장하지 않고 링크로만 연결)
- **업종 묶음:** 공공데이터 업종 12개를 8개 칩(카페·빵, 미용·이발, 생활 묶음 포함)으로 보여 주고 원래 업종은 세부 칩으로
- **모바일·PC 동시 지원:** 모바일은 아래 탭과 바텀시트, PC는 왼쪽 세로 메뉴와 3단 화면·키보드 조작·지도 말풍선
- **저장·최근 본 업소:** 기기 안에만 저장 (회원가입·서버 저장 없음)
- **공유:** 업소별 링크, 카카오톡 미리보기(업소명·가격·사진)
- 다크 모드, 홈 화면 추가(PWA)

## 데이터 처리
공공데이터포털 + 공식 누리집 데이터를 결합하고, 좌표·업체 정보를 여러 출처로 교차 검증했습니다.

| 단계 | 내용 |
|---|---|
| 결합 | 공공데이터 CSV + 공식 누리집 목록·지도 데이터 |
| 좌표 | 공식 좌표 → 카카오 로컬 API로 장소 매칭·보정 |
| 검증 | 네이버 지역검색, 전화번호, 도로명주소, 소상공인 상가정보로 교차 확인 (검수 대상 2,615 → 245건) |
| 앱 데이터 | 시도별 분할, 영업시간 해석, 사진 축소본(360px webp) |
| 자동 검사 | `check_data.py` — ID 유지, 영업시간·시군구 형식, 좌표 범위 등. 실패하면 배포하지 않음 |

업소 ID는 번호 대장(`data/processed/id_registry.json`)으로 관리해 분기 업데이트 후에도 저장·공유 링크가 같은 가게를 가리킵니다.

## 구성
```
app/            배포되는 사이트 (HTML·CSS·JS, data/, thumbs/, assets/)
functions/      Cloudflare Pages Functions — 문장 해석(Gemini 중계), 공식 소식, 공유 미리보기
*.py            데이터 수집·결합·검증·변환 스크립트, server.py(로컬 개발 서버)
docs/           사례 지식·모듈 문서, 버그 이력, 운영 절차, 배포 기록, 디자인 시안(design/)
```

- 화면: 순수 HTML·CSS·JavaScript (프레임워크 없음), 카카오 지도 JavaScript SDK
- 서버: Cloudflare Pages Functions (API 키는 환경변수에만 보관)
- 데이터 처리: Python (pandas, Pillow)

## 로컬 실행
```
python server.py 8000          # http://localhost:8000
python server.py 8000 --lan    # 같은 와이파이의 휴대폰에서 접속
```
`.env`에 API 키가 필요합니다(저장소에는 포함되지 않음). 카카오 개발자 콘솔에 접속 주소를 등록해야 지도가 표시됩니다.
