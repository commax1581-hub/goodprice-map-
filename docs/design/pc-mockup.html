A. 격자형 홈

  • 장점: 처음 온 사용자가 둘러보기 쉬움, 사진 중심이라 시각적으로 풍성
  • 장점: 모바일 홈과 같은 구조라 경험이 일관됨
  • 단점: 지도를 보려면 한 번 더 이동해야 함
  • 단점: 넓은 화면에서 지도라는 핵심 기능이 뒤로 밀림

B. 바로 지도

  • 장점: 열자마자 지도 + 목록 + 상세를 한 화면에서 비교
  • 장점: PC의 넓은 화면을 가장 잘 활용 (네이버·카카오 지도 PC 방식)
  • 단점: 추천 묶음(둘러보기)이 첫 화면에 없음 → 왼쪽 메뉴 '홈'으로 이동해야 봄
  • 보완안: B로 시작하되 목록 상단에 추천 묶음 1줄을 접이식으로 넣을 수 있음
