# 외부 플랫폼 연계·무료 한도 레퍼런스 — 재사용 모듈

> **모듈 문서:** 다른 프로젝트에서도 가져다 쓰는 설계를 모은 문서다. 착한가격 지도가 첫 적용 사례이고, 근거는 [사례지식](사례지식.md) 장 번호와 [버그이력](버그이력.md) 번호(#)로 연결한다.
> 대상: 지도·장소·검색·AI·배포 플랫폼을 **무료·허용된 방식으로** 연계할 때 무엇을 쓸 수 있고, 무엇이 안 되며, 한도가 얼마인지.
> **시간이 지나면 바뀌는 정보**다. 항목마다 확인 시점을 적고, 분기 점검 때 공식 문서와 대조한다. 콘솔에서 실제로 한 설정 절차는 [배포설정기록](배포설정기록.md). 갱신 규칙은 7장.

마지막 확인: 2026-09-21

## 1. 플랫폼 선택 논리 (무료 조건)

| 역할 | 선택 | 이유 |
|---|---|---|
| 기본 지도·좌표·매칭 | **카카오** | 카드 불필요, 공식 누리집도 카카오 기준 좌표, 한 호출로 좌표+장소 ID+링크, 클러스터 기본 제공 |
| 실재 교차검증·후기 | 네이버 API HUB | 장소 ID는 못 주지만 이름·좌표로 검증 가능(2026-07 이후 신규 발급은 API HUB에서만) |
| 구글 | **링크만** | 결제 계정 필요 → 무료 링크로 평점·후기는 사용자가 직접 확인 |
| 주소 검증 | 도로명주소 API(공공) | 저장 제약 없음, 오타·존재하지 않는 주소 전수 검출 |
| 실재 확인 | 소상공인 상가정보 API | 국세청·카드사 기반, **반경 검색**, 건물관리번호·층·호 |
| 인허가(휴폐업) | 시도했으나 보류 | API 100건/회·일 1만 건, 파일 서버 403 → 대체 채널로 해결 |
| AI 문장 해석 | **Gemini 무료 등급** | 카드 불필요. Claude는 이중화 후보였으나 비상업 단계라 보류(키만 넣으면 켜지게 설계) |
| 배포 | **Cloudflare Pages + Functions** | GitHub Pages만으로는 AI 키를 숨길 곳이 없음. 서버 관리 없음·카드 없음 → [사례지식](사례지식.md) 6-1 |

## 2. "크롤링 대신 링크" 원칙

- 네이버 지도 robots.txt는 모든 봇·AI 봇을 명시적으로 차단 → 자동 수집·AI 브라우저 순회 모두 하지 않음(속도가 아니라 **누가 하느냐**가 기준).
- 114(민간 전화번호부)도 상업 DB라 제외. 캡차 우회는 원칙적으로 하지 않음.
- 대신 **공식 API로 애매한 업소만 골라내고, 사람은 링크를 확인**하는 구조.
- 후기·사진 본문은 저장·복제하지 않고 **채널 바로가기**로 연결 → 법적 부담 없음, 앱도 가벼움.
- 공개 사례로서 "**공식 API와 허용된 방식만으로 만들었다**"가 강점이 된다.
- 차단 신호(robots·캡차)는 **멈춤 신호**로 본다.

## 3. 안 되는 것과 대체안 (같은 조사 반복 방지)

**평점·후기 통합 (트립어드바이저식) — 불가**

| 항목 | 가능 여부 | 이유 |
|---|---|---|
| 채널별 평점 통합 비교 | 불가 | 카카오·네이버 평점 API 없음, 구글은 유료·저장 금지 |
| 후기 본문 모아 보기 | 불가 | 저장·복제 금지, 작성자 저작권 |
| 블로그·카페 후기 피드 | **가능** | 네이버 검색 API(제목·요약·링크·**날짜**) |
| 채널 바로가기 | 가능 | 링크 |
| 공식 이용후기 | 링크만 | robots.txt 수집 금지 |
- 대체 설계 **"후기 탐색 허브"**: 채널 바로가기 + 블로그·카페 피드(채널·기간·정렬 필터, 광고성 글 거르기). 제휴 없이 평점을 보여주는 아고다·호텔스닷컴 방식은 불가. (피드는 설계만, 미구현)
  - **사용자 결정(2026-09-22): 구현 시 최근 6개월 게시물만** 보여 준다(최신 정보만). 네이버 검색 API는 날짜순 정렬과 게시일(postdate)을 주므로 6개월보다 오래된 글은 거른다. 구현하려면 네이버 API HUB 키를 Cloudflare 비밀로 등록하고 서버 기능(키 숨김·결과 캐시)이 하나 더 필요하다.
- 장기적으로는 자체 평가(처음엔 "가격이 맞나요?" 같은 가벼운 확인)부터.

**배달앱 연동 — 불가**
- 배민·요기요·쿠팡이츠는 개인 개발자용 공식 API가 없고, 딥링크는 비공식이라 깨지기 쉽다. 배달 가능 업소도 11.3%(1,477곳)뿐.
- 대체: **배달·포장 배지**(공공데이터 기반이라 정확), **전화 주문 버튼**.

**사진 출처**
- 네이버 플레이스 사진: 공식 경로 없음(불가). 네이버 이미지 검색 API: 다른 가게 사진이 섞이고 저작권 불명(비권장). 구글 Places 사진: 가능하나 결제 계정 필요. → **공식 누리집 사진(94.8% 보유, 해당 업소 확실)** 채택. 목록용은 축소본 → [사례지식](사례지식.md) 3-4.

**외부 사이트 수집이 배포 서버에서 막힘** — 공식 누리집이 클라우드 접속을 차단(PC에선 되던 수집이 배포 서버에선 실패) → PC에서 받아 저장본을 함께 배포(#35).

## 6. 플랫폼은 바뀐다 — "작년 방식"을 믿지 말 것

- **네이버 검색 API 이관:** 개발자센터 → ncloud **NAVER API HUB**(2026-06 출시, 2026-07-31 개발자센터 신규 신청 종료, 2027-06-30 기존 키 종료). 주소(`openapi.naver.com` → `naverapihub.apigw.ntruss.com`)와 인증 헤더(`X-NCP-APIGW-API-KEY-ID/KEY`)가 바뀌었다. 처음 안내가 틀려서 사용자가 바로잡았다.
- **카카오 콘솔 개편:** "앱 키" → "플랫폼 키", Web 플랫폼 도메인 → **키마다 도메인 등록**, 공유 링크 도메인은 "제품 링크 관리". 메뉴 위치가 문서와 달라 캡처로 찾아갔다.
- **지방행정 인허가(localdata.go.kr) 폐쇄**(2026-04) → 공공데이터포털로 이관, 파일 서버 403.
- **Cloudflare 환경변수:** `wrangler.toml`이 있으면 대시보드의 일반 변수는 무시됨 → API 키는 **비밀(Secret)** 로 등록(#34).
- **원칙:** 외부 API·콘솔은 기억이 아니라 **현재 공식 문서·실제 화면**으로 확인. 막히면 화면 캡처로 위치를 함께 찾는 게 가장 빠르다.

## 7. 갱신 규칙

- **분기 점검(예약 작업)** 이 1장·4장·5장·6장을 공식 문서와 대조하고, 바뀐 항목만 날짜와 함께 고친 뒤 맨 위 "마지막 확인" 날짜를 바꾼다. 확인 못 한 항목은 "미확인"으로 표시.
- 작업 중 플랫폼 변경·새 함정을 발견하면 즉시 6장에 추가하고, 설정 절차는 배포설정기록에 남긴다.
- "마지막 확인"이 120일을 넘으면 `check_docs.py`가 경고한다.
