# 위치 매칭·정확도 등급 — 재사용 모듈

> **모듈 문서:** 다른 프로젝트에서도 가져다 쓰는 설계를 모은 문서다. 화장실 찾기(`../../화장실`)가 첫 적용 사례이고, 착한가격 지도의 [사례지식](사례지식.md) 원칙(출처·신뢰도·확인일)을 좌표 쪽으로 넓힌 것이다.
> 대상 상황: 공공데이터에 **좌표가 없거나 못 믿을 때**, 주소·이름만으로 지도에 찍어야 하고, **얼마나 믿을 수 있는지를 사용자에게 알려야** 할 때.
> 사건 기록은 화장실 프로젝트의 버그이력(T1~T13), 갱신 규칙은 8장.

---

## 1. 한눈에

```
[주소 정리]  표기 예외 정리(쉼표 행정동·번지/호·붙여 쓴 번호·층 범위)
[주소 검증]  도로명주소 API → 정상 / 모호 / 지역불일치 / 주소없음(=건물 없는 필지)
[좌표]      지도 API 주소검색 → 결과 종류로 등급(A 건물 · B 필지 · C 대략 · X 실패)
[교차 검증]  도로명 좌표 ↔ 지번 좌표가 멀면 어느 쪽이 맞는지 단서로 판단
[이름 매칭]  주소로 안 되면 시설 이름(+주소 속 시설명·건물명)으로 장소 검색 — 두 서비스 일치 여부로 확신 나눔
[표시]      등급별 표시/숨김 + 등급을 사용자에게 고지(뱃지·문구)
[검사]      불변조건 검사 + 골든 표본 + 표본 검수 시트
```

## 2. 주소 정리 — 한국 주소의 예외

| 예외 | 잘못된 처리 | 바른 처리 |
|---|---|---|
| 행정동 이름에 쉼표(`중계2,3동514-4`) | 쉼표 뒤를 버려 `중계2` → 엉뚱한 번지 | 법정동으로(`중계동 514-4`) |
| `692번지`, `473번지 6호` | 지도 API가 못 읽음 | `692`, `473-6` |
| 도로명에 붙은 번호(`산애길100-10`) | 못 읽음 | 띄우기. 단 `473번길`은 그대로 |
| 층 범위(`72 4~7층`) | 뒤가 남아 실패 | 층 이하 제거 |
| 괄호 안 건물명·동명 | 검색어를 흐림 | 검색에서 제거하되 **시설 이름 후보로 보관**(6장) |

- 원칙: **원문은 표시용으로 보존**하고, 정리한 문자열은 조회용으로만 쓴다.
- 함정: Windows curl로 한글 검색어를 보내면 깨져 숫자만 검색된다 — 시험도 실제 코드와 같은 경로로.

## 3. 주소 검증 — 결과가 여러 건일 때

1. 후보가 **모두 같은 건물**이면 채택, 아니면 **주소 끝(도로명+건물번호 / 동·리+번지)이 정확히 같은 후보**만 채택(`봉양로408` ≠ `봉양로408번길 5`).
2. 그래도 안 되면 '모호'로 두고 **좌표를 찍지 않는다**.
3. 결과의 시도·시군구가 원본과 다르면 버린다. 원본의 지역은 **기관 코드**에서 얻는다(주소 자체가 부실할 수 있으므로).
4. **'주소없음' ≠ 틀린 주소**: 도로명주소 DB에는 건물이 있는 곳만 있다. 공원·산책로·계곡은 정상적으로 '주소없음'이 되고, 지도 API가 필지 좌표를 준다.

## 4. 좌표 정확도 등급

| 등급 | 얻는 방법 | 뜻 | 표시 |
|---|---|---|---|
| A 건물 | 주소검색이 건물 주소로 응답 | 건물 위치 | 그대로, 안내 없음 |
| B 필지 | 주소검색이 번지로 응답 | 건물 없는 야외 | 표시, 넓으면 안내 |
| B산 | 번지가 임야 | 산·공원 — 중심점이 실제와 멀 수 있음 | 표시 + "산지에 있음" |
| P 시설 | 이름으로 장소 검색(6장) | 시설 위치 | 표시 + **고지 문구** |
| C 대략 | 도로 중심선·동·리 중심 | 수백 m~수 km 오차 | **숨김** |
| X 실패 | 어디서도 못 찾음 | 원천 주소 오류 | **숨김**(신고 대상) |

- **좌표 하나가 아니라 "어떻게 알아낸 좌표인지"를 함께 저장한다**(출처·등급·확인일).
- 숨김 기준을 정할 때는 **영향도를 수치로** 본다. "확실하지 않으면 숨김"을 그대로 적용했더니 도심 역·지하상가까지 사라진 사례가 있다(화장실 T12: 705곳 숨김 → 규칙 보완 후 5곳).

## 5. 도로명 ↔ 지번이 어긋날 때

두 주소가 300m 넘게 다르면 **어느 쪽이 틀렸는지 경우마다 다르다.**
- 도로명이 틀림: 관청 대표 주소를 기본값으로 넣은 경우(여러 시설이 같은 도로명 공유)
- 지번이 틀림: 본사·본국 주소를 넣은 경우(우체국·지사)

판단 순서: ① 이름 속 읍·면·동이 한쪽 주소에만 있으면 그쪽 ② 이름으로 장소 검색해 300m 안인 쪽 ③ 도로명을 **이름이 다른 3곳 이상이 공유**하면 지번(대표 주소 의심) ④ 그래도 모르면 건물 주소를 유지하고 **확인 목록**으로. 두 지도 서비스가 서로 다른 쪽을 가리키면 숨긴다.

## 6. 이름으로 찾기 — 주소가 막혔을 때의 두 번째 길

- 찾을 이름 후보 순서: **화장실명(시설명) → 주소 끝에 붙은 시설명 → 주소 API가 준 건물명**. 주소 끝 시설명이 의외로 많다(`하늘길 지하77, 김포공항역`, `팔마로 333, 순천팔마종합경기장` — 남은 대상의 28%).
- 확신 나누기: **두 지도 서비스가 150m 안에서 일치 = 확인**, **한 곳에서만 = 추정**. 추정은 표시하되 "정확하지 않을 수 있음"을 고지.
- 이름 비교는 유사도만으로 부족하다 — 같은 0.67에 맞는 것과 틀린 것이 섞인다(`대흥주유소`↔`S-OIL 대흥주유소` ○, `계산역`↔`계산역아파트` ×).
  → **포함 + 종류어 검사**: 우리 이름이 상대에 통째로 들어 있고, 덧붙은 말이 **다른 종류**(아파트·노인정·학원·역·호선·터미널…)가 아닐 것. 단 우리 이름이 이미 같은 종류면 허용(`부천역` → `부천역 1호선`).
- 동명이소 방지: **같은 시군구 안 + 원본 주소에서 5km 안**일 때만 채택.
- 지형 이름 주의: 봉우리·골짜기 이름은 넓은 지역을 가리킨다 → 이름이 같아도 **검증 없이 좌표를 덮어쓰지 않는다**.

## 7. 사용자에게 알리기

| 상황 | 카드(한 줄) | 상세 |
|---|---|---|
| 시설 위치(두 서비스 확인) | 시설 위치 기준 · 입구·안내판 확인 | 정확한 주소가 없어 **시설 이름 기준**으로 안내합니다. 시설 안 어디인지는 알 수 없어요. |
| 추정(한 서비스) | 이름으로 찾은 위치 · 정확하지 않을 수 있어요 | **실제 위치와 다를 수 있어요.** 안내판·안내소나 관계자에게 확인하세요. |
| 넓은 곳(공원·산지·단지) | 범위가 넓어요 · 주차장·입구 쪽 | 지도의 점이 실제 자리와 다를 수 있어요. |

- **가장 정확한 등급에는 아무 안내도 붙이지 않는다** — 안내가 흔해지면 진짜 주의가 묻힌다.
- 뱃지는 색만이 아니라 **아이콘·글자**로도 구분되게(색 구분이 어려운 사용자).
- 포털 장소 링크를 함께 줘서 사용자가 직접 확인할 길을 연다.

## 8. 검사와 갱신

- **불변조건 검사**: 번호 중복·범위 밖 좌표·등급 값·분류 값·파일 크기 → 실패면 배포 중단.
- **골든 표본**: 대표 100곳의 좌표·등급·상태를 고정해 두고 규칙을 고칠 때마다 비교(좌표는 10m 허용).
- **표본 검수 시트**: 갱신마다 새로 매핑된 30곳을 지도·로드뷰 링크와 함께 사람이 확인.
- **조용한 이동 감지**: 같은 영구번호의 좌표가 100m 넘게 움직이면 확인 목록으로.
- **캐시는 자산이다**: 주소·지도 API 캐시를 잃으면 수십만 회를 다시 부른다 → 비공개 백업, 기준본은 보관 정책(최근 8주 전체 → 월 1개 → 연 1개).

## 9. 다른 프로젝트에 적용하는 순서

- [ ] 주소 예외 목록을 **실패 표본에서** 만든다(형식을 미리 짐작하지 말 것)
- [ ] 주소 검증 → 좌표 → 등급을 한 줄에 저장(등급·출처·근거)
- [ ] 숨김 기준을 정하기 전에 **숨는 곳이 무엇인지** 표본으로 본다
- [ ] 주소가 막히면 이름으로 찾는 길을 두되, **두 출처 일치 여부로 확신을 나눈다**
- [ ] 등급을 사용자 화면에 고지(뱃지·문구), 가장 정확한 등급은 조용히
- [ ] 골든 표본·표본 검수·조용한 이동 감지를 갱신 절차에 넣는다

## 11. 갱신 규칙

- 좌표·매칭 관련 버그를 고치면: ① 해당 프로젝트 버그이력에 사건 기록 ② **새 원칙이거나 기준이 바뀌었으면** 이 문서와 10장을 고친다.
- 등급 기준(거리·유사도 임계값)을 바꾸면 4·5·6장 표를 함께 고치고, 골든 표본을 다시 확인한다.
- 특정 프로젝트의 수치는 근거로만 두고, 원칙 문장은 다른 데이터에도 통하게 쓴다.
