# 보기 설정·접근성 — 재사용 모듈

> **모듈 문서:** 어느 앱에서나 쓰는 설계를 모은 문서다. 첫 적용은 화장실 찾기(`../../화장실/docs/사례지식.md` 6-8장), 그다음 앱부터는 **처음부터** 이 규약대로 만든다.
> 담는 것: 밝게/어둡게(야간 모드), 글씨 크기 조절, 누르는 자리 크기, 색 대비, 설정 저장.
> 착한가격 지도의 [사례지식](사례지식.md)이 쌓은 화면 원칙(단어 단위 줄바꿈·색만으로 구분하지 않기)을 설정 축으로 넓힌 것이다.
> 왜: 개인 사례 앱의 사용자는 **어르신·급한 사람·밤에 쓰는 사람**이다. 나중에 붙이면 화면 전체를 다시 손봐야 하지만, 처음부터 지키면 공짜에 가깝다.

---

## 1. 네 가지 규약 (새 화면을 만들 때마다)

1. **색은 토큰만 쓴다** — `var(--ink)`·`var(--paper)`·`var(--line)`…. `#fff`·`#000`을 직접 쓰지 않는다.
2. **크기는 rem으로 쓴다** — 글자도 아이콘도. 1rem = 16px 기준. px로 박으면 큰 글씨 설정이 그 부분만 비켜 간다.
   **예외: 화면 뼈대 폭(300px 이상 레이아웃 폭)·1~2px 선·그림자·미디어 쿼리는 px로 둔다.** 뼈대까지 rem이면 가장 큰 글씨에서 목록·상세가 25% 넓어져 **지도가 밀려난다**(착한가격 2번째 검증). 한 칸짜리 모바일 앱은 이 문제가 없지만, 지도+목록처럼 **영역이 둘 이상이면 반드시 예외로 둔다.**
3. **누르는 것은 최소 44px** — 버튼·칩·목록 줄·**슬라이더**. 어르신, 흔들리는 차 안, 장갑 낀 손.
   글줄 안의 작은 버튼(배지·전화 링크)은 **모양은 두고 `::after`로 누르는 자리만** 넓힌다 — 크기를 키우면 글줄이 흐트러진다.
4. **최소 크기가 필요한 영역은 크기 설정별로 재 본다** — 지도·영상처럼. 조작 막대가 여러 줄인 화면은 큰 글씨에서 막대가 자라 **지도가 36px만 남는 일**이 생긴다. 시트·패널 높이는 화면 비율(`46dvh`)이 아니라 **본문 기준**(`min(46dvh, 100% - 8rem)`)으로 잡는다.
5. **새 화면은 `어둡게` + `가장 큰 글씨`로 한 번씩 보고 넘어간다.** 이 확인만으로 대부분의 사고가 걸린다.

## 2. 어두운 모드 만드는 법

```css
:root{ --bg:#eef1f5; --paper:#fff; --ink:#15202b; --sub:#5b6875; --line:#e3e8ee; … }
:root[data-theme="dark"]{ --bg:#0f141a; --paper:#161d26; --ink:#e8edf3; --sub:#9aa7b5; --line:#2a3644; … }
```

- 색을 **`:root` 토큰 20~25개**로 모아 두면, 어두운 모드는 값만 다시 정의하면 끝난다. 이미 토큰을 쓰고 있었다면 한 시간 안에 된다.
- 기본값은 **기기 설정**(`matchMedia('(prefers-color-scheme: dark)')`), 사용자가 고르면 그 값을 기억한다(밝게 / 어둡게 / 기기 설정).
- **깜빡임 방지**: 저장된 설정을 `<head>`의 짧은 스크립트가 **첫 페인트 전에** `document.documentElement.dataset.theme`에 입힌다. 스크립트를 본문 끝에 두면 흰 화면이 번쩍인다.
- `<meta name="theme-color">`도 함께 바꾼다(주소창·상태바 색).
- 상태 색(열림 초록·주의 주황)은 **어두운 바탕용으로 따로** 고른다. 밝은 배경의 진한 초록은 어두운 배경에서 탁해진다.

### 어두운 모드의 3대 함정

| 함정 | 증상 | 처방 |
|---|---|---|
| 박아 둔 흰색(`background:#fff`) | 흰 판에 흰 글씨 | 전부 `var(--paper)`로 |
| **폼 요소** | `input`에 친 글씨가 **검게** 나옴(색을 물려받지 않는다) | `input,select,textarea{color:var(--ink)}` + `::placeholder` |
| 지도·이미지 | 지도만 하얗게 튄다 | 국내 지도 API는 어두운 타일이 없다 → `filter:brightness(.88)` 정도로 눈부심만 낮추고, 둘레를 어둡게 감싼다 |

## 3. 글씨 크기 조절

```css
html{font-size:16px}
html[data-size="big"]{font-size:18px}    /* +12% */
html[data-size="huge"]{font-size:20px}   /* +25% */
```

- **모든 크기를 rem으로** 바꾸면 루트 한 줄로 글자·아이콘·여백이 함께 커진다. 글자만 키우면 아이콘이 따로 놀아 **더** 읽기 어렵다.
- 큰 글씨에서 같이 풀어 줄 것: **한 줄 말줄임 → 두 줄 허용**(`-webkit-line-clamp:2`), **아이콘 줄 줄바꿈 허용**(안 그러면 끝이 잘린다).
- 화면 폭에 꽉 찬 큰 제목은 rem 대신 `min(45px, 12.5vw)`처럼 **폭 기준**으로 둔다 — 키우면 넘친다.
- 확인 방법: 가장 큰 설정에서 `document.documentElement.scrollWidth > clientWidth`(가로 스크롤)면 어딘가 넘친 것이다.
- **한국어는 `word-break:keep-all` + `overflow-wrap:anywhere`를 전역으로.** 큰 글씨에서 `기반`이 `기/반`으로 끊긴다(착한가격 2번째 검증).
- **이미 만든 앱에 나중에 붙일 때**: px → rem 일괄 변환을 스크립트로 하되(착한가격 737개 중 563개), 위 예외(뼈대 폭·선·그림자·미디어 쿼리)는 빼고 바꾼다. 바꾼 뒤 **가장 큰 글씨에서 화면마다 측정**한다.

## 4. 설정 저장

- `localStorage`에 **설정만** 저장한다. 위치·검색어 같은 개인 정보는 저장하지 않는다(저장하지 않는다고 화면에 밝힌다).
- 저장 실패(사생활 보호 모드)에도 죽지 않게 `try/catch`로 감싼다.
- 키 이름은 앱마다 달라도 된다. **이미 배포한 앱은 쓰던 키를 잇는다**(착한가격 `themeMode` 유지) — 키를 바꾸면 사용자가 해 둔 설정이 초기화된다.
- 설정 입구는 **첫 화면에 보이게** 둔다. 어르신용 기능을 메뉴 깊숙이 넣으면 없는 것과 같다.

## 5. 새 앱 적용 순서

- [ ] 색 토큰부터 잡고 시작(밝게/어둡게 두 벌)
- [ ] 크기는 처음부터 rem
- [ ] 버튼·칩 최소 44px
- [ ] 설정 시트(화면 3 · 글씨 3) + 첫 페인트 전 적용 스크립트
- [ ] 화면 하나 만들 때마다 어둡게·가장 큰 글씨로 확인
- [ ] 지도·영상이 있으면 **크기 설정별 최소 높이**를 잰다
- [ ] 마지막에 대비 점검(본문 4.5:1, 큰 글씨 3:1)
- [ ] 자동 확인: 화면 × 크기 조합에서 **가로 스크롤 0 · 44px 미만 누르는 요소 0**을 스크립트로

## 7. 갱신 규칙

- 새 앱에서 보기 설정 관련 사고가 나면: ① 그 프로젝트 버그이력에 사건을 적고 ② **새 함정이거나 규약이 바뀌었으면** 이 문서와 6장 이력을 고친다.
- 규약(토큰·rem·44px·확인 절차)을 바꾸면 1장과 5장 체크리스트를 함께 고친다.
- 특정 앱의 수치(색 값·픽셀)는 예시로만 두고, 원칙 문장은 다른 앱에도 통하게 쓴다.
